# Prototype: sherlodoc client-side search for stdlib + compiler-libs

A working proof-of-concept of indexing the OCaml **standard library and
compiler-libs** with [sherlodoc](https://github.com/ocaml/odoc/tree/main/sherlodoc)
and exposing the result as **serverless, client-side search** inside
odoc-generated HTML (the `js` database format).

This explores sherlodoc as a modern alternative to the hand-rolled
`search.js` / `index.js` that ships in the compiler manuals today (see
`../../SERVING.md` §6–§7). Compared to the current ocamldoc-scraped index it adds
**type-based search** and covers **compiler-libs** — but it requires the API docs
to be generated by **odoc**, not the legacy **ocamldoc** that produces today's
`libref/` / `api/` HTML.

## Contents

- `reproduce.sh` — end-to-end: isolated opam switch → `odig odoc` → `sherlodoc
  index` (js + marshal) → `odoc html-generate` wired to the search assets → CLI
  smoke test. Regenerates everything; commits no build artifacts.
- `cdp_search_test.py` — drives the **real generated page** in headless Chrome via
  the DevTools Protocol: navigate → focus the search bar → type → read the
  worker-rendered `.search-result` DOM. The end-to-end browser proof.
- `cdp_debug.py` — builds the search Web Worker in-page and captures its
  `onmessage` / `onerror` (used to isolate the load-order bug below).
- `cdp_order.py` — compares the two `importScripts` orders head-to-head.

## Quick start

```bash
./reproduce.sh
python3 -m http.server 8777 --bind 127.0.0.1 --directory ./_html
# open http://127.0.0.1:8777/ocaml/Stdlib/index.html, press '/', search
```

## The pipeline

1. `odig odoc` builds odoc docs for the switch. The stdlib is the `ocaml`
   package; compiler-libs land under `ocaml/compiler-libs/`. A single
   `find .../odoc/ocaml -name '*.odocl'` sweep catches both.
2. `sherlodoc index` consumes `.odocl` (or `.odoc-index`) files and writes a DB.
   `--favoured-prefixes` already defaults to `Stdlib.`. Stdlib submodules
   (`List`, `Map`, …) live *inside* `stdlib.odocl` as children of `Stdlib`, so
   filtering out the `__`-prefixed internal aliases loses nothing.
3. `js` DB (`db.js`) + the jsoo engine (`sherlodoc js` → `sherlodoc.js`) give
   serverless, in-browser search; `marshal` suits CLI/server.
4. `odoc html-generate --search-uri …` wires both JS files into every page's
   search bar. `odoc_search.js` lazily spawns a Web Worker that
   `importScripts()` them and answers queries via `postMessage`.

Verified (OCaml 5.3.0, odoc/sherlodoc 3.2.1): 352 odoc units indexed; name,
docstring, and type/polarity search all return correct hits for both libraries,
confirmed in a real browser — e.g. `List.map`, `: ('a -> 'b) -> 'a list -> 'b
list`, `Cmt_format.read`, `: Env.t`.

## Findings worth keeping (things the CLI path does NOT catch)

1. **`--search-uri` order is reversed from the upstream README.** The worker
   `importScripts(search_urls…)` in flag order, and `sherlodoc.js` calls
   `sherlodoc_db()` **at load**, so the DB must be defined first:

   ```
   odoc html-generate --search-uri db.js --search-uri sherlodoc.js …   # correct
   odoc html-generate --search-uri sherlodoc.js --search-uri db.js …   # README order: FAILS on 3.2.1
   ```
   The wrong order throws `Uncaught TypeError: c.sherlodoc_db is not a function`
   inside the worker — invisible to `sherlodoc search`/`serve`, which never use
   `importScripts`.

2. **The Web Worker is created lazily on the search bar's `focus` event**, then
   fed by `input`. Automation/tests must fire `focus` before typing or `worker`
   is undefined.

3. **Released `sherlodoc 3.2.1` ≠ the in-tree dev source.** The vendored source
   supports repeating `--db`/`-o` to emit several formats in one pass; 3.2.1 does
   not (`--db cannot be repeated`) — so js and marshal need separate index passes.

4. Environment gotchas for the headless-browser check: Chrome's new DevTools
   needs `--remote-allow-origins='*'` for a CDP websocket, and you must disable
   the HTTP cache (or cache-bust the URL) between regenerations or the browser
   serves a stale page.
